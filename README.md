# Цифровой двойник лазерной сварки сплава 1565

Учебный исследовательский симулятор по заданию №2. Реализованы расчётное ядро, валидация, карта P–v, журнал сценариев и экспорт CSV.

## Запуск
1. Установить Python 3.10+.
2. В терминале выполнить:
   `pip install -r requirements.txt`
3. Запустить:
   `streamlit run app.py`

## Файлы
- `app.py` — приложение Streamlit.
- `tests.py` — автоматические тесты контрольного примера и ошибок.
- `sample_experiments.csv` — шаблон для экспериментальных данных.

## Контрольный пример из задания
P=1000 Вт; v=0,6 м/мин; vпр=1,2 м/мин; d=1 мм; rho=2,65 г/см³;
Cосн=4,5%; Cпр=5%; f=0,25; lambda=0,05.
Ожидается: E=100 Дж/мм; A=0,7854 мм²; Q=942,48 мм³/мин;
массовая подача около 2,498 г/мин; q=1,571 мм³/мм;
Cmix=4,625%; Cafter около 4,394%.

В интерфейсе f определяется по эффективным площадям, поэтому для воспроизведения f=0,25 задайте Aприс=0,6 мм² и Aосн=1,8 мм².

## Важные ограничения
Цвет карты означает только расчётную погонную энергию. Это не карта дефектов или безопасности.
Прогнозы глубины проплавления, пористости, потерь Mg и стабильности требуют экспериментальной калибровки.
Программа не управляет сварочным оборудованием и не назначает безопасные режимы.
